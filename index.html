Pipeline

¿Cómo funciona nuestro servicio?

1. Captura

Grabación masiva de sesiones de juego en alta resolución con metadata de inputs y estados del juego.

2. Etiquetado (Opcional)

Anotación de eventos, acciones clave, recompensas y estados visuales para RL y Behavior Cloning.

3. Entrega

Exportación en formatos estructurados listos para ingestión en tu infraestructura de entrenamiento.

Integración

Formato de entrega

Stack VVR v1.2 en producción. Streams binarios versionados + manifest + export para pipelines de entrenamiento.

Formatos de datos

VVR binario (.vvr.zst)

Protocolo abierto · 3 streams por sesión (video + estado + acciones OSA) sincronizados por session_id y epoch-ms.

Manifest v1.2 (JSON)

Metadata por juego/build: plugins, layouts, variables, hashes, sidecars. Un manifest firmado por batch.

Video WebM VP8

144×144 grayscale · 15 fps · particionado por sesión · validado con video_ebml_ok.

Export ONNX / formato personalizado

Export ONNX para inferencia en navegador. También adaptamos a tu stack específico de ML/IA.

Métodos de entrega

S3 particionado

Bucket privado · particionado por juego/fecha · acceso IAM + firmas pre-signed · versionado.

API REST

Query por slug · build · categoría · motor · dispositivo · ventana temporal. Paginación + filtros.

Ingesta en vivo

wss://vvr.monoulabs.ai/ingest · stream TLS directo desde el navegador del jugador al pipeline.

Validación hash-frozen

Cada batch publicado se congela con hash SHA — reproducibilidad total entre corridas de entrenamiento.
